# 日志监控器

这是一个实用的 VS Code 插件，可以实时监控日志文件的变化并在 VS Code 输出面板中显示更新内容。

## 功能

- **实时监控**：实时监控指定的日志文件，当文件内容发生变化时自动更新显示
- **输出面板集成**：在 VS Code 输出面板中展示日志内容，无需切换到其他应用
- **文件变化通知**：显示文件创建、更新和删除的时间通知

## 使用方法

1. 通过命令面板(F1 或 Ctrl+Shift+P)执行"开始监控日志文件"命令
2. 在弹出的文件选择对话框中选择要监控的日志文件
3. 日志内容将显示在输出面板中，并会在文件变化时自动更新
4. 通过命令面板执行"停止监控日志文件"命令可以停止监控

## 开发环境要求

- Node.js (建议 16.x 或更高版本)
- VS Code (1.74.0 或更高版本)

## 开始开发

1. 安装依赖：
   ```bash
   npm install
   ```

2. 编译项目：
   ```bash
   npm run compile
   ```
   
3. 调试运行：
   在 VS Code 中按 F5 启动调试

## 构建和发布

1. 构建插件:
   ```bash
   npm run vscode:prepublish
   ```

2. 打包插件:
   ```bash
   npx vsce package
   ```

## 注意事项

- 如果监控的日志文件很大，可能会影响 VS Code 的性能
- 目前支持单个日志文件的监控，未来版本可能会添加多文件监控功能
